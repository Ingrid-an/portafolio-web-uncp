Semana 01: Introducción y Fundamentos Web

Bitácora de Aprendizaje

Temas tratados:

Conceptos fundamentales del desarrollo web: Frontend, Backend, uso de GitHub para control de versiones y la diferencia clave entre un sitio web y una aplicación web.

¿Qué aprendí?

  • Frontend vs. Backend: El Frontend se encarga de la interfaz visual, el diseño y la interacción con el usuario en el navegador, mientras que el Backend maneja la lógica de negocio, servidores y bases de datos.
  • Sitio Web vs. Aplicación Web: Un sitio web está diseñado para adaptarse responsivamente a cualquier tipo de dispositivo (escritorio, laptop, tablet, móvil), manteniendo la coherencia. En cambio, una aplicación web o nativa puede estar optimizada para un dispositivo específico, modificando drásticamente su comportamiento o disponibilidad al cambiar de pantalla o plataforma.
  • GitHub y Control de Versiones: Aprendí la importancia de gestionar repositorios en GitHub para dar seguimiento al desarrollo del proyecto de forma ordenada mediante commits.

Laboratorio / Práctica:

Configuración inicial del entorno de trabajo, creación del repositorio en GitHub y estructuración del portafolio principal junto con el cuaderno de bitácora.
